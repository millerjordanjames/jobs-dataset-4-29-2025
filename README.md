# linkedin-jobinfotool
Tool to grab job data from the LinkedIn jobs page, including job title, company, location, and listing URL.
Follow all 

SETUP:
1. go to: https://www.linkedin.com/jobs/
2. Open Inspect Element, then go to Console tab.
3. Paste code from "scrapetool.js" into Console then hit enter.
4. This will log all returned text in a spreadsheet-ready format!
